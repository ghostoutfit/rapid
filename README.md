# rapid

A tiny static page that serves the text **Hello Michael** on an animated rainbow background.

## Serve it

It's a single static `index.html`, so any static web server works. Pick one:

```bash
# Python (no install needed on most systems)
python3 -m http.server 8000

# Node, if you have it
npx serve .
```

Then open <http://localhost:8000> in a browser.
